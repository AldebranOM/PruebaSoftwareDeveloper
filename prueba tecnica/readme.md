buen dia, para la ejecucion de este codigo se realiza dese la terminal de comandos con el siguiente comando 
php -S localhost:8080 el cual nos abrira el servidor local de nuestro equipo, estableciendo el puerto al que querramos acceder. 

posterior a estoi, nos dirijiremos a abrir nuestro navegador de peferencia y en la barra de busqueda colocaremos lo siguiente: 

http://localhost:8080

el cual el url consta de nuestro servidor local y el puerto antes ya establecido, esto nos ayudara a poder visualizar nuestro sistema.

para la prueba es muy sencillo, al omoento de cargar nuestra pagina, la interfaz es amigable, ya que el formulario ya hecho nos estara guiando paso por paso al momento de registrar el medico con los campos ya requerido, asi mismo al guardar se puede visualizar el contenido de los docs ya registrados, de igual forma para los pacientes la opcion de seleecionar un medico ya nos tiene precargado lo que vendria a ser el archivo o array jasno con el nombre y la especialidad del medico para la posterior registro del paciente
